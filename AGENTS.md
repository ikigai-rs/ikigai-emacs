# AGENTS.md

`ikigai-emacs` is a thin Emacs client for the ikigai kernel: commands, buffers and an org-mode
workflow that shell to the `ikigai` CLI.

- Read [ACCESSIBILITY.md](ACCESSIBILITY.md) before any change to output people read: messages,
  prompts, buffers, the invitation email, terminal text.
- Run `just gates` (byte-compile, then the ERT suite) before opening a pull request; CI runs the
  same commands.
- Security reports go through
  [private vulnerability reporting](https://github.com/ikigai-rs/ikigai-emacs/security/advisories/new),
  never a public issue.
- Write American spelling (behavior, color, labeled).
